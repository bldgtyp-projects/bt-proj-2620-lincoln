* Note: when constructing unvented rafter assemblies follow all code requirements as per [New York City Building Code 2022](https://up.codes/viewer/new_york_city/nyc-building-code-2022/chapter/12/interior-environment#1203.3)
* Install 4" rigid foam insulation (polyisocyanurate or XPS) over exterior sheathing.
* Primary air-barrier to be [Intello Plus](https://475.supply/products/intello-plus) air and moisture vapor-retarder
  installed along underside of all roof joists. If preferred, substitute A/C plywood. Tape all seams to ensure air and
  moisture-vapor tight.
* Install mineral fiber batt or dense-packed cellulose insulation in existing roof framing cavities.
* Use service cavity / drop-ceiling below air/vapor retarder membrane for all plumbing, electrical, and / or lighting
  fixtures.
